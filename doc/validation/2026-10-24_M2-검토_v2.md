- 작성: 검토자. 독립 재검토만 했다. 코드·설정·다른 문서는 고치지 않았고 커밋하지 않았다. 저장소에 쓴 파일은 이 문서 하나다.

### 1.4 M2-1: 두 프로세스 동시 (`p_2proc.py`, 90초)

- 서버 역할 프로세스: `Engine` 하나로 무작위 질의·모드를 연속 검색한다.
- 쓰기 프로세스: 매 회차 파일 1~4개를 바꾼다(변경·되돌림·삭제·복원·이동). 그다음 **CLI `workmcp scan`**(별도 프로세스)을 돌리고 API `run_index`(HashEmbedder)를 돌린다. `index`의 30 %는 벡터 단계 둘째 배치에서 `KeyboardInterrupt`로 멈춘다.
- 판정 방법:
  - hit의 내용은 쓰기 프로세스가 남긴 내용 원본(sha256별 blob)을 다시 파싱해 대조했다.
  - 대상 여부는 저장소로 확인했다.
  - 대상이 아닌 hit가 나오면 두 경우로 나눴다. 검색 시작부터 확인 끝까지 `data_generation`이 그대로이거나, 검색 시작 전에 이미 대체·삭제된 버전이면 버그로 셌다. 검색 도중 다른 프로세스가 커밋한 경우는 경합(racy)으로 셌다.
