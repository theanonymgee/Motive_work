## 단계 3 — Claude Code (Code 탭)

- 명령: 이 저장소 폴더로 Code 탭 세션을 연다 → 프로젝트 서버 승인 프롬프트(**피터가 승인**) → `/mcp`(안 되면 "workmcp의 status 도구를 호출해 결과를 그대로 보여 줘") → `search`(합성 질의, 코퍼스 Q1 하나) → `get_snippet(chunk_id=<첫 hit>)` → `list_documents(limit=3)` → `recent_changes()`. 필요하면 `…\claude-code\2.1.299\<hash>\claude.exe mcp list`를 시험 홈 프로젝트 폴더에서 실행 [추정].
- 기대: 승인 프롬프트가 뜸 / 도구 5개(`search`, `get_snippet`, `list_documents`, `recent_changes`, `status`) / `status.home == 시험 홈`, `home_virtualization.redirected_to == null` / 각 호출 성공, `search`의 `delivered_sources`가 hit 출처와 같음.
